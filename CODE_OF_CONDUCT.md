# Code of Conduct

## Expected behavior

- Be direct, respectful, and specific.
- Critique code and decisions, not people.
- Keep issue and pull request comments relevant to the project.
- Protect private bookmark data and remove sensitive information from examples.
- Accept maintainer decisions about project scope and safety requirements.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing another person's private information.
- Posting credentials, private browser data, or malicious content.
- Repeated spam, disruption, or bad-faith participation.

## Enforcement

The maintainer may edit, hide, lock, or remove content and may restrict participation when these rules are violated.

Report conduct concerns privately through the contact method on the [maintainer's GitHub profile](https://github.com/mickpletcher). Do not include private bookmark data or credentials. Security vulnerabilities must use the process in [SECURITY.md](SECURITY.md).
